# Base Daily Build Log

A small public learning project that records three daily snapshots of Base Mainnet.

Each day it records:

- Morning snapshot
- Afternoon snapshot
- Evening snapshot

For each snapshot it stores:

- chain ID
- latest block number
- latest block timestamp
- transaction count in the latest block
- gas price
- base fee
- gas used / gas limit
- block delta from the previous snapshot

No wallet, private key, seed phrase, API key, or paid service is required.
